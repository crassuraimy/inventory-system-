# React frontend

This Vite + React app provides starter screens for dashboard, items, purchase drafts, stock-out drafts, monthly register, and reports.

Set `VITE_API_URL` in `.env`. Protected API calls require a Sanctum-compatible bearer token stored in `sessionStorage` under `inventory_token`. A sign-in screen and user administration are intentionally not included yet; connect them before using the application with real inventory.
